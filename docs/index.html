Why Anya

Agents are fast. They also drift.

Without a written source of truth, agents invent requirements, forget constraints, and ship code that “works” but doesn’t match the brief. Anya fixes that with three habits.

✍️

Write the intent once

Vision, stack, and plan live in files — not in a chat that disappears tomorrow.

constitution · stack · plan
🛡️

Validate every step

Specs can’t contradict the constitution. Tasks can’t invent files. Verification can’t assume tests that don’t exist.

5 validation levels
🔁

Close the loop

Every implementation ends with a verification pass and concrete suggestions for the next spec.

verify → next spec

How it works

One pipeline, seven skills

The first three steps run once per project. The rest repeat for every feature — and verification feeds the next spec.

Visionary Product Architect runs once per project

/anya-constitution

Extract the vision, scope, rules, and exclusions from a single prompt. Ask only what’s missing, flag contradictions, and request approval before writing.

Output anya/constitution.md

↻ verify loops back into the next spec — the plan never silently grows.

Flexible Spec 4 sections

For fixes, evolutives, and small tweaks. Fast to write, quick to test.

  • Context & objective
  • Targeted change & expected behavior
  • Criteria & live verification
  • What it does NOT include
Complete Vertical Slice 6 sections

For new features, full user flows, and Walking Skeletons.

  • Context & User Value
  • End-to-End Scope (UI/CLI, Logic, Data)
  • Acceptance criteria & live test steps
  • Required tests & exclusions

The skill adapts between full vertical slices and lightweight specs according to scope.

Quick start

Try it in two minutes

No installer, no package manager, no config file. Copy one folder and talk to your agent.

1

Get the skills

Clone once, drop .anya/ into your project.

bash 
git clone https://github.com/luisresendiz0/anya-sdd.git /tmp/anya-sdd
cp -r /tmp/anya-sdd/.anya /your-project/
cd /your-project
2

Make your agent aware

Global skills (recommended) or project mode — pick your harness.

bash 
# auto-discovery via Agent Skills layout
mkdir -p ~/.config/opencode/skills
cp -r .anya/anya-* ~/.config/opencode/skills/
bash 
# or: .opencode/skills/ · .agents/skills/
mkdir -p ~/.claude/skills
cp -r .anya/anya-* ~/.claude/skills/
AGENTS.md 
# no global install — point your agent at the folder
This project uses Anya-SDD. Before writing code, read
`.anya/anya-<skill>/SKILL.md` and follow it.
Artifacts live in `anya/`.
3

Run the foundation

Three commands, once per project.

agent 
/anya-constitution Task manager for freelancers with multiple clients.
Need projects by client, time tracking, monthly reports, PDF invoicing.
No real-time collaboration or payments.

/anya-stack TypeScript + Express + PostgreSQL. React + Tailwind.

/anya-plan
4

Build one feature

/anya-implement runs /anya-verify automatically and suggests what’s next.

agent 
/anya-spec next
/anya-task login
/anya-implement login

/anya-… is the name of each skill. If your agent doesn’t support slash commands, ask it to load the matching skill by name — the result is the same.

Verification

Six levels. Live interactive testing.

Verification checks every level, confirms build and runtime startup health, generates an Interactive Live Testing Guide, and halts execution for human validation.

  1. L1
    TasksMarked dynamically ([ ], [/], [x]).
  2. L2
    SpecVertical slice criteria and user value met.
  3. L3
    StackImplementation conforms to declared stack.
  4. L4
    ConstitutionBusiness rules and exclusions respected.
  5. L5
    RuntimeCompiles and launches cleanly with run/dev command.
  6. L6
    TestsExact test commands from stack.md — or N/A.

Change management

Philosophy

Minimal by construction

Seven skills, no ceremony, and a folder you can delete without breaking anything.

  • 01

    Zero dependencies

    Only markdown. Nothing to install, nothing to patch.

  • 02

    Portable

    Any agent that reads files can run it.

  • 03

    Pragmatic

    Decisions, not blind automation.

  • 04

    Minimal

    Seven skills. No ceremony.

  • 05

    Token-efficient

    Imperative English, no filler.

What Anya is not

  • ✕
    Not a CLI or code generator. Your agent writes the code.
  • ✕
    Not a project tracker. The plan is a plain markdown table.
  • ✕
    Not a framework you migrate to. Delete the folder and nothing breaks.
